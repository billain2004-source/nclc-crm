# NCLC CRM

Multi-tenant, HubSpot-style CRM: React (Vite) + Node/Express + MySQL.

- App: http://localhost:5173 · API: http://localhost:4000/api
- Start: `powershell -ExecutionPolicy Bypass -File scripts\start.ps1` · Stop: `scripts\stop.ps1`
- First-time setup, logins and everything else: see [documents/](documents/README.md). Start with the [User Manual](documents/User_Manual.md).
